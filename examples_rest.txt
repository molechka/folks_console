Базовый адрес: http://localhost:8088/rest/services/folks/v1
Content-Type для тел запросов: application/json
Даты: dd.MM.yyyy

Поля участника и устройства передаются списком { "name", "value" }.
Устройство — элемент attribute с type = DEVICE.
Перечисления: gender = UNKNOWN | MALE | FAMALE; vipFlag = UNKNOWN | FALSE | TRUE;
type устройства = UNKNOWN | IPHONE | IPAD | SAMSUNG | LENOVO | NOKIA | BLACKBERRY | WINDOWSPHONE | YOTAPHONE | OTHERS;
os = UNKNOWN | IOS | ANDROID | WINDOWS | OTHERS.
Булевы speaker и organizator: true | false.

Ответы create, update и getById возвращают все поля Folk и вложенные DEVICE.
Ниже показан сокращённый вид: в реальном ответе есть и пустые поля.

Изменение
---------
POST /update

Нужен id участника. Обновляются только переданные поля folk. Устройства этим методом не меняются.

Запрос:
{
  "folk": {
    "id": 1,
    "field": [
      { "name": "surname", "value": "Иванов" },
      { "name": "name", "value": "Пётр" },
      { "name": "company", "value": "HFLabs" },
      { "name": "position", "value": "Java Developer" },
      { "name": "city", "value": "Москва" },
      { "name": "speaker", "value": "true" }
    ]
  }
}

Ответ — FolkResponse, как у создания, с актуальными полями участника.
